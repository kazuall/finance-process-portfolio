Holdings and freshness monitoring

My broker, exchanges and wallets update at different times. To value a position, I need to know when the account was read and how recent its price is.

Integrity checks

Holdings stores each observation by source, account and instrument. A missing price leaves the valuation unavailable. Net account value and leveraged exposure have separate fields. The monitoring pilot tracks balance and price timestamps independently and requires a successful, fresh reading before closing an incident.

Verified result

In a synthetic pilot test, the balance was 601 seconds old and its price was 10 seconds old. Only the balance exceeded its threshold (180 seconds for balances, 300 for prices). Repeated checks produced one incident report for that episode.

Bank imports and invoice review

Two bank exports can cover the same transactions. After an interrupted import, I need to determine which entries have already reached the budget. I built an importer for Actual Budget and a separate document intake routine for ADMIN DROP.

Integrity checks

The importer locks the file snapshot, backs up the budget and uses stable transaction IDs across overlapping periods. An uncertain write pauses the watcher until its receipt can be checked. In ADMIN DROP, a fingerprint verifies the original document. Visual review caught an incorrect proposed amount on a cancelled invoice.

Verified result

One recovery added 6 transactions and skipped 280 duplicates. Replaying the same file added 0. An independent read confirmed that entries already in the budget were preserved.

Calendar changes and application replies

A rescheduled invitation can create a second appointment. A reply from an employer can concern just one of two open applications. I use local AI extraction to propose changes and source checks to decide which record can be updated.

Integrity checks

The calendar workflow checks dates, time zone and, for invitation updates, event ID and version. It reads each write back by event ID. The tracker checks that the quote appears in the current message and matches the employer and role. Conflicting evidence goes to human review.

Verified result

A rescheduled interview produced 1 event at the revised time, with 0 actions left on replay. The calendar fix passed 83 tests. In a separate tracker case, a rejection changed only the relevant one of two applications at the same employer.
